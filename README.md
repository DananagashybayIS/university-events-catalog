# university-events-catalog
Каталог мероприятий университета

1. Описание проекта

«Каталог мероприятий университета» — это учебный сайт, где можно смотреть, искать и добавлять информацию о мероприятиях университета.

Проект помогает студентам быстро находить нужные события, узнавать их даты и места проведения.

2. Цель проекта

Создать простой и удобный сайт со списком университетских мероприятий.

3. Основные функции

* Просмотр списка мероприятий.
* Поиск мероприятий по названию.
* Добавление новых мероприятий.
* Указание даты и места проведения.
* Проверка заполнения обязательных полей.
* Отображение количества найденных мероприятий.
* Сброс поиска и просмотр всего списка.

4. Используемые технологии

HTML — создание структуры страницы.

CSS — оформление страницы и кнопок.

JavaScript — поиск, добавление мероприятий и проверка данных.

GitHub — хранение кода проекта.

GitHub Pages — размещение сайта в интернете.

5. Структура проекта

* index.html — содержит страницу, стили и JavaScript-код.
* README.md — содержит описание проекта.

6. Как работает сайт

После открытия сайта пользователь видит список мероприятий.

Чтобы найти мероприятие, нужно ввести его название или часть названия и нажать кнопку «Найти».

Чтобы добавить новое мероприятие, нужно указать его название, дату и место проведения. Если обязательные поля не заполнены, сайт покажет предупреждение.

После добавления мероприятие появится в списке.

7. Ограничения проекта

Сейчас мероприятия хранятся только во время работы страницы. После обновления сайта добавленные мероприятия исчезают.

В будущем можно добавить базу данных, вход для пользователей, редактирование мероприятий и сохранение данных.

8. Результат

В результате создан работающий сайт с каталогом университетских мероприятий.

На сайте можно просматривать, искать и добавлять мероприятия. В проекте использованы HTML, CSS, JavaScript и GitHub.
